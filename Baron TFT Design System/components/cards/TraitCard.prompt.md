Trait / synergy row — hex badge, unit count, breakpoint pips, and effect text. Powers trait panels and comp guides.

```jsx
<TraitCard name="Pháp Sư" count="4 / 6" active tiers={['2','4','6']} activeTier={1}
  description="Tăng sát thương phép cho toàn đội." />
```

Set `active` at a reached breakpoint; `activeTier` fills the pips up to that index.
